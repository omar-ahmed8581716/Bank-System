# Bank Management System (C++)

A C++ console application designed to simulate banking operations, featuring client data management and file persistence.

 Features
- Client Management: Add, search, update, and delete client profiles (CRUD operations).
- Data Persistence: Automatically syncs and updates client data to external text files.
- Validation: Robust input validation using custom loops to prevent invalid entries.
- Data Structures: Utilizes C++ vectors and structs for efficient memory and data handling.

 Tech Stack
- Language: C++
- IDE: Microsoft Visual Studio
- Concepts: Procedural Programming, Structs, Vectors, File I/O (fstream)
